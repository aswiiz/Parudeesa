# 🌿 Parudeesa — Play · Dine · Event Hub

[![Deployed on Vercel](https://img.shields.io/badge/Deployed%20on-Vercel-black?logo=vercel)](https://parudeesa.vercel.app)
[![GitHub](https://img.shields.io/badge/GitHub-aswiiz%2FParudeesa-181717?logo=github)](https://github.com/aswiiz/Parudeesa)

A premium, single-page website for **Parudeesa Lakeside Restaurant**, a luxury Kerala-style lakeside dining and event venue located in Punnamada, Alappuzha, Kerala.

---

## ✨ Features

- 🎬 **Cinematic Hero** — Full-screen video background with animated text overlay
- 📖 **About Section** — Heritage story with traditional Kerala architectural visuals
- 🍽️ **Menu Discovery** — Filterable menu grid showcasing signature Kerala dishes
- 📲 **WhatsApp Food Ordering** — One-click ordering via WhatsApp for each dish
- 📅 **Table Reservation** — Instant seat booking form with confirmation modal
- 🖼️ **Gallery** — Masonry-style photo gallery with lightbox viewer
- ⭐ **Guest Reviews** — Auto-rotating testimonials slider + user review submission form
- 🗺️ **Location & Contact** — Embedded Google Map + full contact details
- 📱 **Fully Responsive** — Optimized for all screen sizes (mobile, tablet, desktop)

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or later recommended)
- npm (comes with Node.js)

### Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/Parudeesa.git

# Navigate into the project folder
cd Parudeesa

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open `http://localhost:5173` in your browser.

### Build for Production

```bash
npm run build
```

The production-ready files will be in the `dist/` folder.
